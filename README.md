## Featured public project

### [Financial Transaction Analysis](financial-analysis/)
A Python workflow for cleaning wallet and savings records, applying description-based transaction rules and comparing monthly inflows and outflows.

- **Methods:** pandas data preparation, rule-based categorisation, cash-flow aggregation and Matplotlib visualisation.
- **Key analytical decision:** distinguish possible internal transfers from income and spending; a transfer narration alone does not establish its economic purpose.
- **Evidence:** [analysis notebook](financial-analysis/financial_analysis.ipynb), [setup and limitations](financial-analysis/README.md), and [dependencies](financial-analysis/requirements.txt).
- **Publication scope:** sanitised code only. Personal transaction data and saved outputs are excluded. The financial classifier uses rules, not a trained machine-learning model; no classification-accuracy claim is made.
